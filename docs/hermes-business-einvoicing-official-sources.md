# Facturation électronique — sources officielles de référence

Dernière vérification: 2026-09-04.

Hermès doit privilégier ces sources officielles avant de répondre à une question réglementaire ou avant de modifier les messages commerciaux.

## Calendrier confirmé

Source DGFiP :
- https://www.impots.gouv.fr/facturation-electronique-et-plateformes-agreees
- https://www.impots.gouv.fr/sites/default/files/media/1_metier/2_professionnel/EV/2_gestion/290_facturation_electronique/fiche-3_tpe_a-partir-de-quand-mon-entreprise-doit-etre-prete.pdf

Source Ministère de l'Économie :
- https://www.economie.gouv.fr/tout-savoir-sur-la-facturation-electronique-pour-les-entreprises

Règles utilisées par le pilote :
- 1er septembre 2026 : toutes les entreprises concernées doivent être en mesure de recevoir des factures électroniques.
- 1er septembre 2026 : grandes entreprises et ETI doivent émettre électroniquement et transmettre les données requises.
- 1er septembre 2027 : PME, TPE et micro-entreprises doivent être en capacité d'émettre électroniquement et de transmettre les données requises selon leur situation.

## Plateformes agréées

Source DGFiP :
- https://www.impots.gouv.fr/actualite/facturation-electronique-publication-de-la-liste-des-plateformes-agreees
- https://www.impots.gouv.fr/facturation-electronique-et-plateformes-agreees

Règle produit : Hermès n'est jamais présenté comme une plateforme agréée. Le service accompagne le client dans l'analyse, le choix, la configuration, les tests et le support autour d'une plateforme agréée ou d'une solution compatible.

## Garde réglementaire

Pour toute réponse client marquée `QUESTION` :
1. utiliser une source officielle fraîche ;
2. ne pas inventer l'assujettissement du client si sa situation n'est pas suffisamment connue ;
3. ne pas produire de conseil fiscal ou juridique personnalisé non vérifié ;
4. si la réponse dépend d'un cas particulier, classer `HUMAN_REVIEW` ou demander les éléments strictement nécessaires au diagnostic ;
5. enregistrer la source et sa date de vérification dans la trace du dossier.

## Message commercial autorisé au 2026-09-04

La formulation « Depuis le 1er septembre 2026, les entreprises concernées doivent être en mesure de recevoir leurs factures électroniques » est conforme au calendrier officiel ci-dessus.

Pour éviter une affirmation trop large, le mot `concernées` doit être conservé lorsque le statut TVA/situation particulière du prospect n'a pas encore été vérifié.
