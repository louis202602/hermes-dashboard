# Espace — real image provenance (public domain)

These wallpapers are optimized WebP derivatives of NASA imagery. NASA still and motion
imagery is generally **public domain** and free to use (see
https://www.nasa.gov/multimedia/guidelines/index.html).

| file                 | source                                                     |
|----------------------|------------------------------------------------------------|
| espace-terre.webp    | NASA — Apollo 17 « Blue Marble », photo id AS17-148-22727   |
| espace-horizon.webp  | NASA — ISS Expedition 43, photo id iss043e091794            |

`*-thumb.webp` are downscaled (~480 px) thumbnails of the same frames for the gallery.
Only cropping / resizing / WebP re-encoding was applied — no content was fabricated.
