# Montagne — real photos to provide

Drop licensed/owned WebP files here (see /docs/wallpaper-assets.md for the exact
filenames + subjects), add a `<name>-thumb.webp` (~480px) alongside each, then register
one `kind:"image"` entry per file in `lib/dashboard/wallpapers.ts` with REAL provenance.

Expected files:
- montagne-neige.webp        (+ montagne-neige-thumb.webp)        — snowy peaks
- montagne-alpine.webp       (+ montagne-alpine-thumb.webp)       — alpine valley / snowy forest
- montagne-crepuscule.webp   (+ montagne-crepuscule-thumb.webp)   — mountain sunset

Do NOT add images whose licence does not clearly permit product embedding. Never fabricate provenance.
